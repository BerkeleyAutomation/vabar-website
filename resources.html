Materials

VABAR is built entirely on open-source tools and runs on a GPU workstation as well as on Isaac Lab Arena. Everything below is released at github.com/BerkeleyAutomation/VABAR, available by Nov 9.

Code
Benchmark and harness

Task environments, instance generator, evaluator and baseline runner, on both the Newton and ILA implementations.

Assets
Standardised library

55+ assets normalised in format, scale, appearance and collision geometry.

Skills
33 generalizable skills

Perception, grasping, motion planning and execution, and verification — with human-authored reference graphs per task.

Instances
Seeded instance sets

The N = 30 instance sets per task–difficulty cell used for every reported number.
